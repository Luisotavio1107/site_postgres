# Raia Sports (loja esportiva em PHP)

Requisito: PHP 7.4+ (nenhuma extensão de banco necessária).

Windows: dê dois cliques em iniciar.bat. Ou, no terminal:

    php -S localhost:8000

Dados: database/usuarios.json e database/pedidos.json (criados no primeiro cadastro/compra).
Produtos: edite database/produtos.php.
Estrutura: includes/ · login/ · app/ · database/ · assets/
